# 视觉内容生成

根据用户目标选择图片生成或 3D 转换；不要为了展示能力而同时调用两者。

## 决策规则

- 用户需要新图片时使用 `image_generation`，在一次调用中表达主体、环境、构图、风格、比例和必须保留的文字或物体。
- 用户明确需要 3D 结果时使用 `image_to_3d`。已有可用图片时直接提交；刚生成图片时复用本轮生成结果，不猜测本地路径或外部 URL。
- 生成任务成功提交与最终产物完成是不同状态。只按工具实际返回的状态、标识和产物引用回答。
- 不把生成结果描述成真实拍摄、官方设计或已获授权的资产；涉及真人、品牌和敏感内容时遵守当前安全与授权边界。

## 执行流程

1. 明确交付类型、视觉重点和格式约束；只有缺失信息会显著改变结果时才追问。
2. 调用最直接的生成工具，并保留返回的任务或产物标识。
3. 需要连续转换时，把前一步成功结果作为后一步输入；前一步失败则停止依赖链并说明。
4. 最终只交付工具实际产生的引用、状态和必要限制。
