# 04 意图识别与 Tool Router

## 1. 目标

Agent 必须能自主识别用户意图，并决定使用 LLM 内生能力、VLM、图片生成、3D 渲染、搜索比价或记忆系统。

## 2. 意图分类

| intent | 含义 | 示例 |
|---|---|---|
| chat | 普通对话/解释 | “这个风格怎么样？” |
| understand_image | 图片理解 | “图里是什么？” |
| understand_video | 视频理解 | “视频里发生了什么？” |
| search_product | 商品搜索 | “帮我找相似款” |
| compare_price | 商品比价 | “哪个平台便宜？” |
| generate_image | 图片生成 | “生成一张海报图” |
| render_3d | 3D/场景渲染 | “放到客厅看看效果” |
| retrieve_memory | 记忆检索 | “上次那个黑色包” |
| save_memory | 保存记忆 | “记住我喜欢日系风” |
| multi_tool_task | 多工具任务 | “找相似款，比价，再生成海报” |
| ask_followup | 信息不足需追问 | “这个”但没有上下文 |

## 3. 路由规则

优先级：

1. 如果指令涉及“上次、刚才、之前、我喜欢”，优先检索记忆。
2. 如果输入包含视频/图片且用户要求理解内容，调用 VLM/Video VLM。
3. 如果用户要求找商品、同款、相似款，调用商品搜索。
4. 如果用户要求价格、便宜、平台、预算，调用比价。
5. 如果用户要求生成图片、海报、换背景、风格图，调用图片生成。
6. 如果用户要求放入场景、3D、渲染、模型，调用渲染。
7. 如果单步无法完成，生成多步骤 TaskPlan。
8. 如果关键信息缺失，进入 AskFollowup。

## 4. 多工具规划示例

用户：

```text
帮我找视频里的鞋子，比较价格，然后生成一张日系海报。
```

规划：

```text
1. video_understanding: 识别视频中的商品
2. product_search: 搜索相似鞋子
3. price_compare: 对搜索结果按价格排序
4. image_generation: 基于选定商品生成日系海报
5. memory_save: 保存本次商品和用户偏好
```

## 5. 初期实现建议

MVP 使用规则分类器 + 关键词 + 输入媒体类型即可。不要一开始依赖真实 LLM 分类。

后续替换为 LLM/VLM 分类器时，仍保持同一个 `IntentDetector` 接口。
