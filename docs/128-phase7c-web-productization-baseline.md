# 128 Phase 7C Web Productization Baseline

## Goal

Upgrade the simple Web Console into a minimal usable product surface for pilot users.

## Scope

- Scenario picker improvements.
- Browser-session request history.
- Run detail panel.
- Trace detail panel.
- Tool-call timeline.
- Capability badges.
- Loading and error states.
- Runtime profile/provider mode indicator.

## Out of Scope

- No complex frontend framework unless explicitly chosen.
- No payment, checkout, crawling, or marketplace behavior.
- No production analytics SDK.
- No default real Provider calls.

## Success Criteria

- User can run core flows from Web Console.
- Tool calls and errors are visible.
- Trace/run IDs are accessible.
- Default behavior remains mock/local.
