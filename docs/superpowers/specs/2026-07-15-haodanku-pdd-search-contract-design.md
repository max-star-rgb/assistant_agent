# 好单库多平台搜索真实契约修复设计

## 目标

修复京东、拼多多搜索的分页参数，并统一处理 LLM 可能生成的中文平台名，使默认离线测试与真实 `provider_smoke` 使用同一适配器。平台未授权时仍保留其他平台的部分成功结果，并完成 Gateway `<detail>` 输出。

## 设计

- 拼多多搜索使用真实响应确认的 `back` 参数，不再发送 `limit`。
- 将中立的 `top_k` 向上归一化到 `10,20,...,100`；适配器仍只返回每平台前 `top_k` 条。
- 京东的 `top_k` 向上归一化到 `1,2,5,10,20,30,50`。
- 淘宝继续沿用现有 linked-item overfetch。
- `淘宝/天猫/京东/拼多多` 在搜索和比价过滤前归一化为 `taobao/jd/pdd`，避免 Provider 成功后被中文过滤值误删。
- 京东或拼多多权限失败继续记录在 `failed_platforms/platform_errors`，不得终止淘宝结果。
- 更新本地好单库商品接口文档，以真实响应证据记录两个平台的 `back` 取值。

## 验证

- 单元测试断言京东、拼多多 URL 使用归一化后的 `back` 且不含 `limit`。
- 单元测试覆盖中文平台名在搜索和比价两个阶段的归一化。
- 目标测试覆盖三平台并发、部分失败、比价和 Gateway presenter。
- 真实 `provider_smoke` 先区分平台成功、参数失败和权限失败，再通过 DeepSeek Gateway 验证工具治理、单个 `<detail>` chunk 和 `run.end`。

## 外部条件

京东和拼多多官方权限必须由用户在好单库侧开通；该外部条件不通过代码绕过。
