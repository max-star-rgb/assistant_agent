# 四、调试排错篇 - 详情

---

## 🔴 原题

用户反馈：Agent 回答时说"我记得你之前说预算是 1000"，但实际上用户从来没说过这句话。这是典型的"记忆幻觉"问题。

请回答：
1. 你会按什么顺序排查这个问题？请列出具体的检查步骤
2. 可能的根因有哪些？请至少列举 3 种
3. 怎么设计"防幻觉机制"，从根本上减少这类问题？

---

## Q1. 记忆幻觉的排查与防御 🔴

### 【面试官点评】

✅ **答对的部分**：
- 知道要排查上下文摘要和长期记忆
- 想到了"上下文压缩后错误召回"这个根因

❌ **不足的地方**：
1. **缺少系统化的排查流程**：没有从外到内、从易到难的排查顺序（先看 API 返回，再看 trace，再看内存，最后翻代码）
2. **根因分析太浅**：没有触及"记忆检索本身就是基于 embedding 的近似匹配"这个本质问题
3. **防幻觉机制完全没答到点上**：这是面试的核心区分点

---

### 【标准答案】

#### 1. 系统化排查流程（从外到内，从易到难）

```
步骤 1：查当前轮次的 prompt（最直观）
  ↓ 看 memory_text 字段里到底有什么
  ↓ 如果里面已经有"预算 1000"→ 问题出在记忆注入阶段

步骤 2：查 memory retrieval trace（检索阶段）
  ↓ 看检索到的 memory items 是哪些
  ↓ 看每个 item 的 similarity score
  ↓ 如果某个不相关的记忆分数很高 → 问题出在 embedding 检索

步骤 3：查 context_summary（压缩阶段）
  ↓ 看 context_summary 里有没有"预算 1000"
  ↓ 如果有 → 压缩阶段生成了错误摘要

步骤 4：查长期记忆库（存储阶段）
  ↓ 用用户 ID 直接扫库，看是否真的存了这条记忆
  ↓ 如果有 → 之前某轮错误写入了

步骤 5：查写入策略（写入阶段）
  ↓ 看那条错误记忆的 source 字段是什么
  ↓ 如果是 auto-promoted → 自动提升策略太松了
```

#### 2. 可能的 5 种根因（按出现概率排序）

| 根因 | 概率 | 具体表现 |
|-----|------|---------|
| **1. embedding 检索误召** | ⭐⭐⭐⭐⭐ | "预算"这个词 embedding 太接近了，某条"笔记本预算 5000"的记忆和当前 query 相似度排进了 Top-K |
| **2. context_summary 压缩失真** | ⭐⭐⭐⭐ | 多轮压缩后，LLM 摘要器"脑补"了不存在的细节，尤其是"用户说过"这种语气的句子 |
| **3. 记忆提升策略太松** | ⭐⭐⭐ | `MemoryPromotionCandidate` 的置信度阈值设得太低，Agent 自己的思考被当成了用户输入 |
| **4. ToolObservation 被误判为用户说的** | ⭐⭐ | 工具返回的结果里有"预算 1000"，LLM 读了 observation 后忘了是谁说的 |
| **5. 跨会话串扰** | ⭐ | 多用户并发下，user_id 边界没隔离好，A 用户的记忆跑到了 B 用户的上下文里 |

#### 3. 防幻觉机制设计（3 层防御）

这是面试区分"会用"和"会设计"的关键：

| 防御层 | 机制 | 具体做法 |
|-------|------|---------|
| **第一层：检索时防误召** | 相似度双阈值 + 来源标记 | `score > 0.85` 直接用；`0.7 < score < 0.85` 加前缀「**疑似记忆**：我好像记得...」；`score < 0.7` 直接丢弃。**所有记忆前面必须加来源标记**：`[用户说过]` / `[工具返回]` / `[Agent 思考]` |
| **第二层：注入时加边界** | 记忆 fence + 指令强化 | 记忆块前后加明确的分隔符：`===== 以下是历史记忆，不是当前对话 =====`。System Prompt 里明确写：**"如果记忆内容和当前对话矛盾，以当前对话为准；如果不确定是不是用户说的，就反问确认"** |
| **第三层：生成时可溯源** | 记忆引用 ID + 事后审计 | 每条注入的记忆都带 `[MEM-123]` 标记。如果 LLM 引用了这条记忆，输出里必须带上 `[依据 MEM-123]`。事后如果发现幻觉，直接查是哪条记忆被误召了 |

**面试金句**：
> "记忆幻觉本质上是一个**边界问题**——LLM 分不清'我看到的信息来自哪里'。解决方案不是让 LLM 变聪明，而是**用工程手段强化边界**，让 LLM 每说一句话都知道自己在引用什么。"
